# ADR 001: Make the readout and evaluation independent of the model architecture

Status: accepted 2026-09-22; implementation evidence updated 2026-09-23.

The handoff proposes a diffusion-to-AR hybrid. Current evidence already includes
strong diffusion-only and Gemma AR implementations. A hybrid-first implementation
would obscure whether either component can solve the task alone within budget.

Decision: use a typed candidate-scoring interface, calibrate every frozen backend
separately, compare Gemma 4 12B against DiffusionGemma structured reads, and require
quality, cost and damage gates before implementing a learned bridge. Calibration
is intended to use separate semantic groups and is bound to the scorer configuration. Original
evidence always remains available to refinement. OpenJeff retains its chosen name.

Initial consequence: there is no requirement to ship a hybrid. The implementation
update below supersedes the original scaffold status.
The $200 cap includes setup/idle/storage/API overhead; plan to stop at $150.


## 2026-09-23 implementation update

The AR-only candidate-scoring path now has a trained 12B LoRA adapter, independently
fitted calibrators, a tested loopback endpoint, and a public-subset transfer test.
The normalized-state audit found repeated logical states across synthetic splits;
the semantic-group separation goal is not met by unique case IDs alone. The release
reports this explicitly, including a 403-case final slice without a normalized
training-state match. Calibration under new domain distributions remains unproven. The chosen
pilot is AR-only; optional diffusion evidence remains separate. No learned bridge
is required for this release. See `reports/RESULTS.md` and `reports/diffusion-attempt.json`.
