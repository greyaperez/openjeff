# OpenJeff logo

`openjeff-logo.png` is the primary project logo, generated with the built-in image generation tool. The name-badge mascot nods to the project's deliberately chosen “My name is Jeff” reference; its bracket expression connects the joke to code.

The transparent PNG is intended for light backgrounds. The original generation prompt is saved in `prompt.txt`.

`openjeff-logo-dark.png` is the dark-mode companion, made with the built-in image
generation tool. It preserves the badge and pose while using ivory lettering,
limbs, and an outer keyline on an opaque dark backdrop. The final edit prompt is
saved in `prompt-dark.txt`. The root README selects the appropriate edition with
GitHub's supported `picture`/`prefers-color-scheme` markup.
