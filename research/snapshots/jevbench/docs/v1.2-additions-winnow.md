# Winnow-12B Q8 measurement — native endpoint, provenance fixed for the run

Measured 21 Sep 2026 at model revision
`b6ac22b0d51b69b18200acacb3fbdd98073fffe8` and inference revision
`6c2b3c04e248a319f2cb43832628eba03e55fe38`. The Q8_0 GGUF SHA-256 is
`b710efc4c0d048ee61eed92c5fef5ce323a4d17e7c51f9f0533cc72ae50818ea`.

Winnow is a LoRA fine-tune of `google/gemma-4-12B-it`, merged and exported as
GGUF. The release and the applicable Gemma 4 base/derivative terms are
Apache-2.0; the release retains the base attribution and modification notice.
The separate inference repository is MIT and builds on llama.cpp.

The frozen v1.2 set and scorer are unchanged. The author's server implements
the TypeSafe-compatible `/v1/systemone` request and response directly, so there
is no benchmark-specific label mapping: exact state, question type,
instructions, criteria and score levels pass through the existing TypeSafe
adapter. Native answer probabilities are scored as returned. Inference is
serial, one request at a time, with no retries, option-order ensemble or fitted
calibration. The submitted Q8 profile used an 8,192-token context, four
decision branches, Q8 KV cache and full GPU offload.

The endpoint ran on our lium.io RTX 4090 and was reached over the internet from
Germany. Cost is not treated as free: the estimate uses the nearest hosted 12B
Gemma reference, OpenRouter's `google/gemma-3-12b-it` at $0.05 per million
input tokens, applied to the endpoint's measured input-token counts; typed
decisions read logits and generate no answer tokens.

The private training dataset is not released. The author's report says its
checksum-verified 16,000-example initial mixture and 26,000-example refinement
mixture were scanned against all 231 public JevBench records, finding zero
exact normalized input/state matches and zero high-containment candidates.
That claim cannot be independently reproduced without the rows. Our scan of
73 released text artifacts found zero exact public state matches and zero exact
instruction matches. The public JevBench evaluation was known and reported by
the author before this submission; public-benchmark development is allowed and
is disclosed.
