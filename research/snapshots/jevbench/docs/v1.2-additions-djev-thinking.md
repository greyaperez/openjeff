# djev thinking measurement (v1.2.12)

This addition uses the unchanged frozen 534-decision JevBench v1.2 set and scorer.

`Davipar/djev-dev` revision `3ce907e` is an Apache-2.0 runtime over
`google/diffusiongemma-26b-a4b-it`. Its published route hard-codes
`enable_thinking=false`, `diffusion_max_steps=1`, and `read_only=true`; it does
not currently expose a thinking/effort switch. The underlying DiffusionGemma
chat template and runtime do support thinking. The row therefore measures an
experimental full-generation path over that same checkpoint, with thinking
enabled and one configuration frozen for the complete run:

- BF16 on one lium.io H200, serial requests;
- `enable_thinking=true`;
- maximum 8,192 generated tokens;
- the final complete JSON probability object is parsed without repairing or
  changing values;
- every unparseable response is a benchmark failure.

The run attempted all 534 decisions. It returned a valid distribution for 462;
72 failed to return a parseable distribution within the contract. Cost counts
measured input and output tokens for every attempt, including failures, at a
same-size public hosted reference tariff. The row also reports the measured
serial H200 rental equivalent as sensitivity, excluding setup and idle time.

This is a new entrant/configuration row. No earlier answer, task, score, or
methodology changed.
